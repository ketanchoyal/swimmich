# Task: i18n

Status: plan

## Plan

**Objectif**: Compléter l'internationalisation. Textes actuellement en FR/EN hardcoded, catalogue Localizable.xcstrings partiel. Objectif: tous les textes externalisés, support toutes langues iOS.

**Hypothèses** (ground truth vérifié):
- `Localizable.xcstrings` existe dans le projet.
- iOS 26 → `.strings catalogs` natif.
- Textes hardcodés dans les Views (labels, placeholders, error messages, titles, sheets, empty states).
- Erreurs API retournées en anglais par le serveur.
- UserDefaults pour language selection `appLanguage`.

**Approche retenue**: A — `.localized` / `Text("key")` + Localizable.xcstrings complété + language picker + DateFormat hoisting.
**B (rejetée)**: Framework tiers → inutile sur iOS 26.
**C (rejetée)**: Fichiers `.strings` classiques → String Catalogs sont le standard moderne.

**Étapes**:
1. Audit strings hardcodés dans tous les Views.
2. Compléter Localizable.xcstrings avec ≥200 clés (FR + EN).
3. Migration de TOUS les string literals en `String(localized:)` ou `Text("key", bundle: .module)` dans:
   - Auth: LoginScreen, WelcomeScreen, ServerURLScreen
   - Timeline: TimelineView
   - Viewer: PhotoViewer, PhotoInfoPanel, PhotoEditor
   - Albums: AlbumsView, AlbumDetailView
   - Search: SearchView, MapView
   - Memories: MemoriesView
   - People: PeopleView
   - Tags: TagsView
   - Admin: AdminView
   - Upload: UploadViewModel (BackupSettingsView)
   - SharedLinks: SharedLinksView
   - Trash: TrashView
   - Profile: ProfileView
   - Settings: PushNotificationSettingsView, etc.
4. NEW `LanguageSettingsView` (Features/Settings/) — Liste langues + toggle "Use System Language".
5. NEW `LanguageSettingsViewModel` (Features/Settings/) — selectedLocale, useSystemLanguage, applyLanguage, languages.
6. NEW `AppDateFormat` (DesignSystem/) — DateFormatters réutilisés pour éviter allocations hot paths.
7. Tests — LocalizationTests +3 (vérifier traductions complètes pour 3 écrans).
8. Build + suite complète.

**Écarts au contrat, assumés** :
1. **AC-3802** : la vérification grepait la vue pour `UserDefaults`/`appLanguage` ; la persistance est dans `AppLanguageStore` (corrigé ci-dessus). Comportement identique, meilleur découpage.
2. **Pas de bouton « Relaunch »** dans le toast (le brief UI le demandait) : iOS n'expose aucune API de relance d'app, le bouton aurait été mort. Le bandeau dit à la place ce qui se passe (« Some text updates after you reopen the app. » + « Got It »), et la retraduction immédiate est réelle — vérifiée à l'écran.
3. **Langues au-delà de FR+EN** : décision utilisateur du 2026-09-14 — le catalogue porte fr/de/es/it.
4. **Limite connue** : le titre de la barre de navigation ne se retraduit pas à chaud (ponté vers UIKit) ; il suit au lancement suivant, comme le reste de ce que le toast annonce. Le corps de l'écran, lui, se retraduit immédiatement (vérifié : `App-Sprache` après sélection de l'allemand).
