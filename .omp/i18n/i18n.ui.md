# Task: i18n — UI Brief (Liquid Glass Primary)

## Design Philosophy

L'internationalisation est un feature transversal mais l'écran de sélection de langue est un **parcours vitré** : chaque langue est une cellule glass, le toggle système est un switch interactif, et le toast de relance est un panneau flottant. C'est exactement comme les réglages de langue iOS — propre, fluide, et profond.

## Layout

```
ProfileView (Me hub)
└── Form
    └── Section "General"
        └── NavigationLink: Language → LanguageSettingsView (glass screen)

LanguageSettingsView
└── NavigationStack (scrollEdgeEffectStyle: glass)
    ├── ImmichAppBar (glass bar)
    └── ZStack {
        ├── Background: subtle blurred photo
        └── GlassEffectContainer {
            ├── LanguageRow (glass card for each language)
            ├── LanguageRow
            ├── LanguageRow
            └── System toggle row — glass card
        }
        .padding(PVSpacing.s16)
```

### LanguageToast — Glass toast for relaunch
```
ZStack (overlay on current view)
└── LanguageToast (glass floating bar)
    ├── Icon — glass pill
    ├── "Language changed. Tap to relaunch."
    ├── "Relaunch" button — glass pill
    └── "Later" button — glass pill
```

## Components

### LanguageSettingsView — Glass language selection

```swift
struct LanguageSettingsView: View {
    @State var vm: LanguageSettingsViewModel
    @Namespace private var glassNamespace
    
    var body: some View {
        NavigationStack {
            ZStack {
                Color.immichBackground.ignoresSafeArea()
                
                GlassEffectContainer {
                    Form {
                        Section {
                            ForEach(vm.languages, id: \.code) { locale in
                                LanguageRow(locale: locale, isSelected: vm.selectedLocale == locale)
                                    .glassEffect(.regular)
                                    .glassEffectID("lang_\(locale.code)", in: glassNamespace)
                            }
                        }
                        .onChange(of: vm.selectedLocale) { _, newLocale in
                            if let newLocale, newLocale != Locale.autoupdatingCurrent {
                                vm.applyLanguage(newLocale)
                            }
                        }
                        
                        // System language — glass toggle row
                        SystemLanguageRow(isOn: $vm.useSystemLanguage)
                            .glassEffect(.regular)
                    }
                    .formStyle(.grouped)
                }
                .padding(PVSpacing.s16)
            }
            .toolbar { ImmichAppBar(title: "Language") }
        }
    }
}
```

### LanguageRow — Glass language selection

```swift
struct LanguageRow: View {
    let locale: AppLocale
    let isSelected: Bool
    let onSelect: () -> Void
    @Namespace private var rowNamespace
    
    var body: some View {
        Button(action: onSelect) {
            HStack(spacing: PVSpacing.s12) {
                Text(locale.displayName)
                    .font(.pvBody.weight(.semibold))
                    .foregroundStyle(isSelected ? Color.immichPrimary : .primary)
                    .glassEffect(isSelected ? .regular : .identity)
                
                Spacer()
                
                Text(locale.nativeName)
                    .font(.pvSubhead)
                    .foregroundStyle(.secondary)
                    .glassEffect(.regular)
                
                if isSelected {
                    Image(systemName: "checkmark")
                        .font(.pvBody)
                        .foregroundStyle(Color.immichPrimary)
                        .glassEffect(.interactive())
                        .frame(width: 24, height: 24)
                }
            }
            .frame(height: 44)
            .padding(PVSpacing.s12)
            .glassEffect(isSelected ? .regular : .identity)
            .glassEffectID("lang_row", in: rowNamespace)
        }
    }
}
```

### SystemLanguageRow — Glass toggle

```swift
struct SystemLanguageRow: View {
    @Binding var isOn: Bool
    
    var body: some View {
        HStack(spacing: PVSpacing.s12) {
            VStack(alignment: .leading, spacing: PVSpacing.s2) {
                Text("Use System Language")
                    .font(.pvBody.weight(.semibold))
                Text("Match your device language")
                    .font(.pvCaption)
                    .foregroundStyle(.secondary)
            }
            Spacer()
            Toggle("", isOn: $isOn)
                .toggleStyle(.switch)
                .tint(Color.immichPrimary)
                .glassEffect(.interactive())
                .frame(width: 40, height: 24)
        }
        .padding(PVSpacing.s12)
        .glassEffect(.regular)
    }
}
```

### LanguageToast — Glass relaunch toast

```swift
struct LanguageToast: View {
    @Namespace private var toastNamespace
    
    var body: some View {
        HStack(spacing: PVSpacing.s12) {
            Image(systemName: "globe")
                .font(.pvBody)
                .foregroundStyle(Color.immichPrimary)
                .glassEffect(.regular)
                .frame(width: 32, height: 32)
            
            Text("Language changed. Tap to relaunch.")
                .font(.pvBody)
                .lineLimit(1)
            
            Spacer()
            
            Button("Relaunch") { dismiss() }
                .font(.pvSubhead.weight(.semibold))
                .foregroundStyle(Color.immichPrimary)
                .glassEffect(.interactive())
            
            Button("Later") { dismiss() }
                .font(.pvSubhead)
                .foregroundStyle(.secondary)
                .glassEffect(.interactive())
                .frame(width: 32, height: 32)
        }
        .padding(PVSpacing.s12)
        .glassEffect(.regular)
        .scrollEdgeEffectStyle(.floating) // Floats at bottom
    }
}
```

## Interactions

### Select Language
- Tap any language row → glass shimmer on selected row + haptic `.selection`
- Visual: checkmark appears with `.contentTransition(.symbolEffect(.replace))`
- Background tints with `.immichPrimary.opacity(0.08)`
- Persists in UserDefaults("appLanguage")
- Relaunch toast: glass floating bar at bottom
- Tap "Relaunch" → app background/foreground cycle
- Tap "Later" → dismiss; language applies on next launch

### System Language Toggle
- `.glassEffect(.interactive())` on the switch
- Checkmark moves to "System" row with `PVMotion.snappy` (0.25s, damping 0.75)
- Relaunch app to apply

## Liquid Glass (iOS 26 — PRIMARY)

### Philosophy
- **Toutes** les language rows sont des cartes vitrées
- **Groupes** de controls dans `GlassEffectContainer`
- **Checkmark** comme badge vitré interactif
- **Shimmer tactile** sur tous les éléments interactifs
- **Toast relaunch** flottant en glass

### Specific applications
1. **Language rows** : Glass cards — each language is a glass cell
2. **Checkmark** : `.glassEffect(.interactive())` — tactile shimmer
3. **Native name** : Small glass pill with language name
4. **System toggle** : Glass interactive switch
5. **Toast** : Glass floating bar with `scrollEdgeEffectStyle`
6. **Toast buttons** : Glass interactive pills

### Background
- Subtle blurred photo behind glass settings — depth

## Accessibility

- Glass cards maintain contrast via `.regular` glass (auto adjusts for Reduce Transparency)
- Language row: `.accessibilityLabel("Select language: \(displayName) (\(nativeName))")`
- System toggle: `.accessibilityLabel("Use system language: \(isOn ? "on" : "off")")`
- Toast: `.accessibilityLabel("Language changed. Tap to relaunch the app.")`
- All elements ≥ 44×44pt
- Reduce Motion: glass morphs → opacity crossfade, no shape change

## Animations

- Language selection: background color change with `PVMotion.snappy` (0.25s, damping 0.75)
- Checkmark appearance: `.contentTransition(.symbolEffect(.replace))`
- Toast appearance: `.move(edge: .bottom).combined(with: .opacity)` — spring 0.35s
- Toast dismissal: reverse animation
- Reduce Motion: background tint stays; no slide animations
